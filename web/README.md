# Роберт Веб — платформа уроков ИИ в браузере

Версия проекта «Робот Роберт» без установки: менторы открывают ссылку в **Chrome/Edge**,
нажимают «Подключить робота» — и всё работает через Web Bluetooth. Python не нужен.

## Оболочка `app.html`: связь не рвётся при переходах

В Chrome Bluetooth-подключение принадлежит странице и теряется при переходе по ссылке. Поэтому все
разделы открываются внутри `app.html` (iframe): оболочка держит робота, а меню переводит только рамку.
Любая прямая ссылка (`blockly.html#example-diag_clean`) сама заворачивается в
`app.html#blockly.html#example-diag_clean`, старые ссылки менять не нужно. Внутри рамки `robert.js`
находит `parent.Robert._host` и делегирует ему связь; свой Bluetooth не трогает.

## Страницы

Между страницами есть бургер-меню, но каждую можно отдать отдельной ссылкой. Студентам по блочному
программированию — только `blockly.html`, менторам — панель и диагностику, страницы ИИ — отдельно.

| Файл | Урок |
|---|---|
| `index.html` | Панель: речь робота, записанные фразы (голос Роберта), пульт, глаза, чек-лист ментора |
| `diagnostika.html` | Диагностика: сценарий на 45 минут кнопками по этапам, имена детей подставляются в фразы, чек-лист на 5 пунктов, ссылки на заготовки блоков. Фразы звучат записанным голосом Роберта из `audio/diag/<кнопка>-<номер>.mp3` (записи ElevenLabs, тексты в `diag_phrases.js`). Фразы с именами детей озвучивает ElevenLabs API тем же голосом: ментор вставляет свой ключ и выбирает голос на странице (хранится в браузере), готовый звук кешируется в браузере. Голос браузера не используется |
| `blockly.html` | Блоки: программирование Роберта блоками, как в Scratch (Google Blockly) — события, движение, глаза, речь, циклы, условия, переменные, свои блоки |
| `tm.html` | Teachable Machine (картинки и позы) → реакции робота |
| `follow.html` | «Следуй за мной»: лицо / ладонь / свой объект из TM |
| `sound.html` | Звуковые команды (аудио-модель TM) |
| `chat.html` | «Спроси Роберта»: ответы Gemini голосом робота (каждый со своим бесплатным ключом) |

## Деплой на Vercel

1. [vercel.com](https://vercel.com) → Add New → Project → импортировать репозиторий
   (или `npx vercel` в этой папке).
2. Root Directory: `web`. Framework: **Other**. Build command — пустой (это статика).
3. Deploy → раздать менторам ссылку.

Подойдёт и любой другой статический хостинг (GitHub Pages, Netlify): сайт обязан быть
на **HTTPS**, иначе браузер не даст Web Bluetooth, камеру и микрофон.

## Требования

- Chrome или Edge на Windows / macOS / Android (iPhone и Firefox не умеют Web Bluetooth).
- Интернет: библиотеки ИИ грузятся с CDN, ответы — из Gemini.
- Чтобы голос шёл из робота, сопрягите его в системе как Bluetooth-колонку
  (Параметры → Bluetooth → Добавить устройство → Robert).
- Ключ Gemini каждый получает бесплатно на aistudio.google.com/apikey и вставляет
  на странице «Спроси Роберта» — ключ хранится только в браузере ученика.
