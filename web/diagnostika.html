Каждая кнопка говорит одну из нескольких фраз, робот не повторяется.

Имена детей

Через запятую, как в записи на диагностику. Нажмите «Подготовить» заранее: фразы с именами озвучатся голосом Роберта и будут играть без задержки.

Голос для имён (ElevenLabs)

Ключ: elevenlabs.io → Profile → API Keys. При выпуске ключа включите права Text to Speech и Voices: Read, иначе список голосов не загрузится и ID придётся вписать вручную. Голос выберите тот, которым записаны остальные фразы. Ключ хранится только в этом браузере.

Чистая программа Программа с ошибкой

Чистая: только начало программы, дети говорят, что делать, ментор добавляет блоки из разделов Звук, Движение, Внешность, Танцы. С ошибкой: робот идёт назад вместо вперёд, дети ищут, где ошибка.

Голос

Обычные кнопки звучат записанным голосом Роберта из папки audio/diag. Кнопки с именами детей озвучивает ElevenLabs тем же голосом. Голос браузера не используется.
