# Робот Роберт — Codify

> 🌐 Есть **веб-версия без установки** — папка [`web/`](web/): менторы открывают ссылку в Chrome,
> робот подключается прямо из браузера (Web Bluetooth). Деплой на Vercel — см. [web/README.md](web/README.md).
> Для диагностик есть страница **«Диагностика»** — сценарий на 45 минут кнопками, фразы записаны голосом Роберта (`web/audio/diag/`).
> В веб-версии есть страница **«Блоки»** — программирование Роберта блоками, как в Scratch (Google Blockly).
> Версия ниже (Python) — тег `local`.

Программа для уроков по искусственному интеллекту в IT-школе Codify с танцующим роботом **Robert RS01**:
панель ментора (робот говорит ваш текст), Teachable Machine, управление жестами и голосом,
игра «Камень-ножницы-бумага».

Работает на **Windows 10/11** и **macOS**. Установка — один раз на ноутбук ментора, около 10 минут.

---

## Чек-лист установки: Windows

- [ ] Скачать проект: зелёная кнопка **Code → Download ZIP** на этой странице и распаковать в удобную папку (например, на Рабочий стол).
- [ ] Установить **Python 3.11 или 3.12** с [python.org](https://www.python.org/downloads/windows/).
      В первом окне установщика поставить галочку **Add python.exe to PATH**.
- [ ] Дважды щёлкнуть **`setup_windows.bat`** в папке проекта и дождаться надписи «Готово!» (5–10 минут, нужен интернет).
- [ ] Включить робота (долгое нажатие кнопки на груди, 5 секунд).
- [ ] Сопрячь робота как колонку: **Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth → Robert**.
- [ ] Проверить: дважды щёлкнуть **`mentor_panel.bat`** → в браузере откроется панель → статус «Робот подключён» → нажать «Произнести» — голос звучит из робота.

## Чек-лист установки: Mac

- [ ] Скачать проект: **Code → Download ZIP** и распаковать.
- [ ] Установить **Python 3.11 или 3.12** с [python.org](https://www.python.org/downloads/macos/) (не из App Store).
- [ ] Открыть **Терминал**, набрать `cd ` (с пробелом), перетащить папку проекта в окно Терминала и нажать Enter.
- [ ] Выполнить в Терминале: `bash setup_mac.command` и дождаться надписи «Готово!» (5–10 минут).
- [ ] Скачать русский голос: **Системные настройки → Универсальный доступ → Устный контент → Системный голос → Управлять голосами → Русский → Milena**.
- [ ] Включить робота и сопрячь его: **Системные настройки → Bluetooth → Robert → Подключить**.
- [ ] Проверить: дважды щёлкнуть **`mentor_panel.command`** (если macOS не даёт открыть: правый щелчок → **Открыть** → **Открыть**).
- [ ] Разрешить Терминалу доступ к **Bluetooth**, **Камере** и **Микрофону**, когда macOS спросит.
- [ ] Статус «Робот подключён» → нажать «Произнести» — голос звучит из робота.

## Программы

| Windows | Mac | Что делает |
|---|---|---|
| `mentor_panel.bat` | `mentor_panel.command` | Панель ментора: текст голосом робота, фразы, движения, чек-лист урока, Teachable Machine, «Следуй за мной» (робот поворачивается за лицом, ладонью или своим объектом из TM), «Звуковые команды» (аудио-модель TM: свои слова, хлопки, свист), «Спроси Роберта» (ответы нейросети голосом робота; нужен бесплатный ключ Gemini с aistudio.google.com/apikey в файле `gemini_key.txt`, либо ключ Anthropic в `claude_key.txt`) — http://localhost:8000 |
| `start.bat` | `start.command` | Пульт управления: ходьба, танцы, цвет глаз |
| `voice.bat` | `voice.command` | Голосовое управление: «вперёд», «танцуй», «привет», «стоп» |
| `gestures.bat` | `gestures.command` | Управление жестами через камеру (MediaPipe) |
| `rps.bat` | `rps.command` | Камень-ножницы-бумага с роботом, режим «умный Роберт» учится на ходах игрока |
| `lesson_start.bat` | `lesson_start.command` | Приветствие перед уроком |

Робот держит **только одно подключение**: перед запуском другой программы закройте окно предыдущей.

## Частые проблемы

| Что видно | Что сделать |
|---|---|
| «Робот не найден» | Робот сам выключается через 8 минут без команд — включите его и нажмите «Подключить» |
| Голос звучит из ноутбука, а не из робота | Робот не сопряжён как колонка — выполните шаг с Bluetooth из чек-листа |
| «Нет доступа к камере» | Камеру держит другая программа или вкладка — закройте её |
| Teachable Machine: полоски стоят на 0% | Обновите страницу (Ctrl+F5 / Cmd+Shift+R); под кнопками появится текст ошибки |
| Mac: робот не находится | Разрешите Терминалу Bluetooth: Системные настройки → Конфиденциальность и безопасность → Bluetooth |

## Для разработчиков

- `robot_ble.py` — протокол робота (BLE, сервис `FFC0`, запись в `FFC1`, пакет `AA AA CC 32 01 … 55 55`).
- `robert_sdk.py` — простая библиотека для учеников: `Robert().say("Привет")`, `.forward(2)`, `.hands()`, `.eyes(3)`.
- `platform_compat.py` — различия Windows и macOS: голос, камера, шрифт.
- `phrases.py` — фразы робота и словарь произношения (IT → «айти», Codify → «Кодифай»).
- Модели: `models/vosk-model-small-ru-0.22` (распознавание речи, Apache 2.0), `models/gesture_recognizer.task` (MediaPipe, Apache 2.0).
