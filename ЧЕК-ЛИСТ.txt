РОБЕРТ — ЛОКАЛЬНАЯ ВЕРСИЯ ЧЕРЕЗ BLUETOOTH WINDOWS
=================================================

Чем отличается от сайта: роботом управляет маленькая программа на ноутбуке
через системный Bluetooth, а не Chrome. Окна «выберите устройство» нет,
робот ищется сам, после первого раза — по запомненному адресу. Страницы те же:
панель, диагностика, блоки, Teachable Machine и остальные.


УСТАНОВКА (один раз, 10 минут)
------------------------------
[ ] 1. Распаковать архив целиком в удобную папку, например на Рабочий
       стол. Внутри должны лежать: ЗАПУСК.bat, local_server.py и папка web.
[ ] 2. Установить Python 3.11 или 3.12 с python.org/downloads/windows.
       В первом окне установщика поставить галочку «Add python.exe to PATH».
       Если Python уже стоит, пропустить.
[ ] 3. Дважды щёлкнуть ЗАПУСК.bat. При первом запуске он сам скачает
       библиотеку Bluetooth (1–2 минуты, нужен интернет) и откроет страницу.
[ ] 4. Включить робота: длинное нажатие кнопки на груди, 5 секунд.
[ ] 5. Сопрячь робота как колонку, чтобы голос шёл из него:
       Параметры → Bluetooth и устройства → Добавить устройство →
       Bluetooth → Robert. Нужно один раз.
[ ] 6. На странице нажать «Подключить робота». В чёрном окне появится
       «Ищу робота…» и через несколько секунд «Подключено».
[ ] 7. Проверить: нажать стрелку «вперёд» на панели, робот идёт.
       Нажать готовую фразу, голос звучит из робота.


ПЕРЕД КАЖДЫМ УРОКОМ (2 минуты)
------------------------------
[ ] 1. Включить Bluetooth на ноутбуке.
[ ] 2. Включить робота (кнопка на груди 5 секунд), дождаться, пока он
       встанет и глаза загорятся.
[ ] 3. Дважды щёлкнуть ЗАПУСК.bat. Откроется Chrome со страницей,
       рядом чёрное окно. Чёрное окно НЕ закрывать до конца урока.
[ ] 4. Нажать «Подключить робота», дождаться зелёного статуса.
[ ] 5. Нужна другая страница: открыть меню (три полоски слева от
       логотипа). Робот остаётся подключённым при переходе между
       страницами.
[ ] 6. После урока: нажать «Отключить», закрыть чёрное окно,
       выключить робота.


ЕСЛИ НЕ ПОДКЛЮЧАЕТСЯ
--------------------
Чёрное окно пишет причину простыми словами. Самые частые:

«робот не найден»
  [ ] Робот включён? Глаза горят?
  [ ] Робот рядом, в 1–2 метрах?
  [ ] Bluetooth на ноутбуке включён?
  [ ] Выключить робота, подождать 5 секунд, включить, через 10 секунд
      нажать «Подключить» снова.

«робот не отвечает, скорее всего подключён к другому устройству»
  [ ] Робот держит одну связь. Закрыть приложение на телефоне,
      закрыть вкладку сайта airobot на этом и других ноутбуках,
      закрыть другие окна программы Роберта.
  [ ] Перезагрузить робота (выключить и включить).

«на ноутбуке выключен Bluetooth»
  [ ] Параметры → Bluetooth и устройства → включить.
  [ ] Если включён, а ошибка остаётся: выключить и включить Bluetooth,
      затем нажать «Подключить» снова.

«local_server.py не отвечает»
  [ ] Чёрное окно закрыли. Запустить ЗАПУСК.bat заново.

Связь обрывается посреди урока
  [ ] Это нормально при помехах. Программа сама переподключается,
      статус на странице через несколько секунд снова станет зелёным.
  [ ] Если не вернулся за минуту: перезагрузить робота.

Голос звучит из ноутбука, а не из робота
  [ ] Выполнить шаг 5 из установки (сопрячь робота как колонку).
  [ ] В Windows внизу справа щёлкнуть значок звука и выбрать
      устройство вывода Robert.

ЗАПУСК.bat сразу закрывается или пишет «Не найден Python»
  [ ] Установить Python с python.org с галочкой «Add python.exe to PATH».
  [ ] После установки перезапустить ноутбук и запустить снова.

Страница открылась не в Chrome
  [ ] Скопировать адрес http://localhost:8765 в Chrome или Edge.
  [ ] Страницы ИИ (камера, микрофон) работают только в Chrome и Edge.


ПОЛЕЗНО ЗНАТЬ
-------------
- Адрес робота после первого подключения лежит в файле robot_address.txt
  рядом с ЗАПУСК.bat. Если робота заменили на другого, удалите этот файл.
- Робот засыпает через 8 минут без команд. Программа сама шлёт ему
  «пульс» раз в минуту, пока подключена, так что на уроке он не уснёт.
- Интернет нужен для страниц ИИ (библиотеки грузятся из сети) и для фраз
  с именами детей на диагностике. Панель и пульт работают без интернета.
- Сайт airobot и локальная версия используют одного робота. Одновременно
  работать может только одна из них.
